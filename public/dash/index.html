물동량 추이

한국 · 중국 금액

한국 금액 = 수입 Collect + 수출 Prepaid, 중국 금액 = 수출 Collect. 수입 Prepaid(중국 지불)는 저장하지 않아 미집계입니다.

공컨 이송

공컨 B/L(B/L Type E)은 물동량 TEU 에 넣지 않고 여기서만 TEU 로 셉니다. TEU = 20'·20RF ×1 + 40'·40RF·45' ×2. 표의 증감률은 TEU 기준 직전 월(항차) 대비입니다.

현재 화면의 조회 조건(기간·업체·ITEM·화물 종류 등)과 월별·항차별 선택을 그대로 보고서로 만듭니다. 한 달만 조회하면 항차별로 만듭니다.

데이터 올리기

수입 · 수출은 B/L 번호로 자동 구분합니다(수출 = …W0001). 한 파일에 섞여 있으면 받지 않습니다. 이미 있는 B/L 은 새 값으로 덮어씁니다.
수입 = 화물 도구 운임 필터 탭의 [클라우드 동기화]와 같은 저장(운임 필터 · 운임 체크에도 반영). 수출 = 대시보드 전용(운임 필터 · 운임 체크에는 영향 없음).
ACT 자가 장치장 목록 = 첫 열에 B/L 번호가 있는 취합 엑셀(B/L NO 머리글 없음). 올릴 때마다 목록 전체가 이 파일로 바뀝니다(특송 도착지 구분에만 사용).
